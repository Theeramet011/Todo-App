# โฟลเดอร์ `android/app` (Android Application Module)

โฟลเดอร์นี้เป็นส่วนสำคัญหลัก (Module) สำหรับแอปพลิเคชันระบบปฏิบัติการ **Android** ในโครงการ Flutter ทำหน้าที่รวบรวมไฟล์โค้ดของฝั่ง Android Native, ทรัพยากรระบบ (Resources) และการตั้งค่าคอนฟิกูเรชันต่างๆ สำหรับคอมไพล์และสร้างแอป (Build APK / App Bundle)

---

## 📂 โครงสร้างภายในโฟลเดอร์ `app`

### 1. `src` (Source Code & Resources)
โฟลเดอร์เก็บโค้ดต้นฉบับและส่วนติดต่อของฝั่ง Android:
*   **`main/kotlin` หรือ `main/java`**: เก็บไฟล์ซอร์สโค้ดภาษา Kotlin/Java (เช่น `MainActivity.kt`) สำหรับเรียกใช้งานฟังก์ชันของระบบ Android หรือฟีเจอร์ระดับระบบปฏิบัติการ
*   **`main/res`**: เก็บไฟล์ทรัพยากรสำหรับการแสดงผลในฝั่ง Android เช่น ไอคอนแอป (Mipmap), รูปภาพ (Drawable) และไฟล์คอนฟิกสไตล์ธีม (Values)
*   **`main/AndroidManifest.xml`**: ไฟล์ประกาศสิทธิ์การเข้าถึงข้อมูลระบบ (Permissions), กำหนดกิจกรรมหลัก (Activities) และข้อมูลเมตา (Metadata) ของแอปพลิเคชัน
*   **`debug` / `profile`**: โฟลเดอร์ที่เก็บค่าคอนฟิกแยกตามสถานะการพัฒนา (Environment) เช่น สิทธิ์การเข้าถึงระบบอินเทอร์เน็ตเฉพาะการทดสอบ (Debug Permission)

### 2. `build.gradle.kts` (Module Build Configuration)
ไฟล์ควบคุมการคอมไพล์ระดับโมดูล (Module-level Gradle) ทำหน้าที่:
*   กำหนด **Application ID** (Package Name)
*   ตั้งค่าเวอร์ชันของ SDK ขั้นต่ำที่รองรับ (**minSdkVersion**) และเวอร์ชันที่พัฒนา (**targetSdkVersion**)
*   จัดการ Dependencies ที่จำเป็นต้องดึงมาใช้งานเฉพาะในฝั่ง Android เท่านั้น

### 3. `google-services.json` (Firebase Configuration)
ไฟล์คอนฟิกเชื่อมต่อบริการของ **Google Firebase** (เช่น Cloud Firestore, Cloud Messaging, Auth, Storage) สำหรับแพลตฟอร์ม Android เพื่อให้แอปพลิเคชันหน้าบ้านสามารถติดต่อเชื่อมโยงกับฐานข้อมูลเบื้องหลังได้ถูกต้องแม่นยำ

---

## 🎯 หน้าที่หลักของโฟลเดอร์นี้
1.  **เชื่อมต่อไปยัง Android OS:** เป็นพื้นที่กำหนดสิทธิ์เข้าใช้งานความสามารถของสมาร์ทโฟน Android เช่น การขอสิทธิ์แสดงการแจ้งเตือน (Notifications) หรือสิทธิ์อ่านมีเดีย
2.  **จัดการการคอมไพล์:** จัดแจงกระบวนการสร้างและบีบอัดไฟล์แอปพลิเคชันสำหรับนำไปติดตั้งบน Android
3.  **ตั้งค่าระบบความปลอดภัย:** ใช้กำหนดสิทธิ์เข้าถึงตามข้อกำหนดใหม่ๆ ของระบบปฏิบัติการ Android (เช่น Android 13+)
