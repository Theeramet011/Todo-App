# โฟลเดอร์ `functions` (ระบบหลังบ้าน)

โฟลเดอร์นี้เปรียบเสมือน **"ผู้ช่วยส่วนตัวที่ทำงานอยู่เบื้องหลัง"** ของแอปพลิเคชัน (หรือที่เรียกกันว่า Cloud Functions) 

## โฟลเดอร์นี้มีหน้าที่ทำอะไร?
หน้าที่หลักของโค้ดในโฟลเดอร์นี้คือการจัดการงานที่ต้องรันอยู่บนเซิร์ฟเวอร์อัตโนมัติโดยที่แอปบนมือถือไม่ต้องทำเอง เช่น:

- **คอยจับเวลาและส่งแจ้งเตือน:** เป็นระบบนาฬิกาปลุกที่คอยเช็กตลอดเวลาว่า งานไหนใกล้เดดไลน์แล้ว งานไหนเลยกำหนดเวลา หรือมีใครเตือนใครบ้าง แล้วจะส่งข้อความแจ้งเตือน (Push Notification) เด้งไปที่หน้าจอมือถือของผู้ใช้งาน
- **ทำงานอัตโนมัติตามตาราง:** มีฟังก์ชันที่ตั้งเวลาให้รันอัตโนมัติทุกๆ นาที เพื่อตรวจความเคลื่อนไหวของภารกิจต่างๆ อย่างแม่นยำ

## ไฟล์สำคัญ
- **`index.js`**: เป็นไฟล์โค้ดหลักที่เป็นเหมือนสมองสั่งการ รวบรวมคำสั่งส่งการแจ้งเตือนและการตั้งเวลาทำงานทั้งหมดไว้ที่นี่
- **`package.json`**: เป็นไฟล์ที่เก็บรายชื่อเครื่องมือหรือส่วนเสริมต่างๆ (ไลบรารี) ที่ผู้ช่วยหลังบ้านตัวนี้ต้องใช้ในการทำงานให้สำเร็จ
