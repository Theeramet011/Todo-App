# โฟลเดอร์ `models` (โครงสร้างข้อมูล)

โฟลเดอร์นี้เปรียบเสมือน **"แม่พิมพ์"** หรือ **"แบบแปลน"** ของข้อมูล

ใช้เก็บโค้ดที่กำหนดว่าข้อมูลแต่ละประเภทควรมีหน้าตาและองค์ประกอบอย่างไร เช่น:
- **ข้อมูลผู้ใช้งาน (User):** ต้องมี ชื่อ, รูปโปรไฟล์, คะแนนสะสม
- **ข้อมูลภารกิจ (Task):** ต้องมี ชื่อภารกิจ, วันครบกำหนด, สถานะว่าทำเสร็จหรือยัง

การมีแม่พิมพ์นี้ช่วยให้แอปพลิเคชันเข้าใจข้อมูลตรงกัน ไม่ดึงข้อมูลผิดพลาด และทำงานได้อย่างเป็นระเบียบ
