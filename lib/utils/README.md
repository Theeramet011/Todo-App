# โฟลเดอร์ `utils` (เครื่องมืออเนกประสงค์)

โฟลเดอร์นี้เปรียบเสมือน **"กล่องเครื่องมือช่าง"** 

ใช้เก็บฟังก์ชันเล็กๆ น้อยๆ หรือเครื่องมือตัวช่วยที่มักจะถูกเรียกใช้งานบ่อยๆ จากหลายๆ ที่ในแอปพลิเคชัน เพื่อให้ไม่ต้องเขียนโค้ดเดิมซ้ำๆ เช่น:
- ฟังก์ชันแปลงรูปแบบวันที่และเวลาให้อ่านง่าย
- ฟังก์ชันตรวจสอบความถูกต้องของอีเมลที่พิมพ์เข้ามา
- ฟังก์ชันคำนวณขนาดหน้าจอ
- ข้อมูลจำลอง (Mock Data) สำหรับเอาไว้ทดสอบระบบ
