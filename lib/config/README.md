# โฟลเดอร์ `config` (การตั้งค่าแอป)

โฟลเดอร์นี้เปรียบเสมือน **"สมุดจดการตั้งค่าหลัก"** ของแอป

ใช้เก็บไฟล์ที่กำหนดค่าพื้นฐานต่างๆ ที่ต้องใช้ซ้ำๆ ทั่วทั้งแอปพลิเคชัน เช่น:
- ธีมสีของแอป (Colors)
- รูปแบบและขนาดตัวอักษร (Typography)
- ค่าคงที่ต่างๆ (Constants)

**ข้อดี:** หากในอนาคตต้องการเปลี่ยนโทนสีของแอป ก็สามารถมาแก้ไขที่นี่เพียงจุดเดียว สีทั้งแอปก็จะเปลี่ยนตามทันที
