# โฟลเดอร์ `providers` (ตัวจัดการสถานะและข้อมูล)

โฟลเดอร์นี้เปรียบเสมือน **"ผู้ประกาศข่าว"** ประจำแอป

มีหน้าที่เก็บและจัดการสถานะ (State) ของข้อมูลต่างๆ ภายในแอป เมื่อมีการกระทำใดๆ ที่ทำให้ข้อมูลเปลี่ยนแปลง (เช่น ผู้ใช้งานกดทำภารกิจเสร็จแล้วได้คะแนนเพิ่ม) Provider จะคอยกระจายข่าวไปบอกหน้าจอต่างๆ ที่แสดงคะแนนอยู่ ให้ทำการอัปเดตตัวเลขแสดงผลแบบเรียลไทม์ โดยที่ผู้ใช้ไม่ต้องกดรีเฟรชหน้าจอ
