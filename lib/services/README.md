# โฟลเดอร์ `services` (ตัวกลางเชื่อมต่อ)

โฟลเดอร์นี้เปรียบเสมือน **"พนักงานรับส่งเอกสาร"** ของแอป

ทำหน้าที่เป็นตัวกลางในการติดต่อสื่อสารกับระบบภายนอก หรือระบบหลังบ้าน (เช่น Firebase) โดยโค้ดในนี้จะไม่ได้ยุ่งเกี่ยวกับการวาดหน้าตาแอป แต่จะเน้นเรื่องการจัดการข้อมูล เช่น:
- การนำข้อมูลงานไปบันทึกลงฐานข้อมูล (Database)
- การไปดึงข้อมูลผู้ใช้งานมาจากเซิร์ฟเวอร์
- การจัดการเรื่องระบบแจ้งเตือน (Notifications) หรือการอัปโหลดไฟล์รูปภาพ
