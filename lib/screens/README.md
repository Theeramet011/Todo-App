# โฟลเดอร์ `screens` (หน้าจอแอปพลิเคชัน)

โฟลเดอร์นี้เปรียบเสมือน **"ห้องต่างๆ ในบ้าน"** 

ใช้เก็บโค้ดที่สร้าง "หน้าจอ" แต่ละหน้าของแอปพลิเคชัน ที่ผู้ใช้งานจะมองเห็นและโต้ตอบด้วย เช่น:
- หน้าเข้าสู่ระบบ (Login Screen)
- หน้าจอหลัก (Home Screen)
- หน้าแสดงรายละเอียดภารกิจ (Task Detail Screen)
- หน้าดูประวัติคะแนน (Profile Screen)
