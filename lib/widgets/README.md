# โฟลเดอร์ `widgets` (ชิ้นส่วนหน้าจอ)

โฟลเดอร์นี้เปรียบเสมือน **"ชิ้นส่วนเลโก้"**

ใช้เก็บชิ้นส่วน UI (User Interface) เล็กๆ หรือองค์ประกอบของหน้าจอที่สามารถนำไปต่อประกอบ หรือหยิบไปใช้งานซ้ำๆ ได้ในหลายๆ หน้าจอ (Reusable Components) เช่น:
- ปุ่มกดที่มีดีไซน์เฉพาะตัวของแอป
- การ์ดสี่เหลี่ยมสำหรับแสดงรายการภารกิจ
- กล่องข้อความกรอกข้อมูล
- แถบเมนูด้านล่าง (Bottom Navbar)

การแยกชิ้นส่วนเหล่านี้มาเก็บไว้ จะช่วยให้โค้ดในหน้าจอหลักสั้นลง อ่านง่ายขึ้น และประหยัดเวลาในการสร้างหน้าจอใหม่ๆ
