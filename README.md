# 🎮 Todo App: Gamified & Collaborative Task Management

แอปพลิเคชันจัดการภารกิจและโครงการกลุ่มที่ผสมผสานแนวคิดเกม (**Gamification**) เข้ากับการทำงานร่วมกันเป็นทีม (**Collaboration**) เพื่อช่วยเพิ่มความสนุกในการทำงาน รักษาวินัยในการจัดการเวลา และอำนวยความสะดวกในการจัดสรรงานกลุ่มอย่างมีประสิทธิภาพ

---

## 🚀 ภาพรวมของระบบ (Project Overview)

โปรเจกต์นี้ได้รับการพัฒนาขึ้นด้วย **Flutter** สำหรับฝั่งผู้ใช้งาน (Frontend) และใช้ **Firebase** ในการจัดการระบบหลังบ้าน (Backend) โดยความพิเศษของแอปพลิเคชันนี้คือการเปลี่ยนการเคลียร์งานธรรมดาให้กลายเป็นความท้าทายด้วยระบบเก็บเลเวล ปลดล็อกตราความสำเร็จ (Achievements) และสะสมกรอบโปรไฟล์สุดพิเศษ พร้อมทั้งมีระบบการทำงานร่วมกันเป็นทีมที่ตอบโจทย์ตั้งแต่การกระจายงานย่อยไปจนถึงการรีวิวผลงานโดยหัวหน้ากลุ่ม

---

## ✨ คุณสมบัติเด่นของระบบ (Key Features)

### 1. ระบบจัดการภารกิจส่วนตัว (Personal Tasks)
* **การจัดการงานอย่างละเอียด:** สามารถกำหนดชื่อภารกิจ รายละเอียด วันเวลาเดดไลน์ และระดับความสำคัญ (Priority: Low, Medium, High, Urgent)
* **การตั้งเตือนแบบยืดหยุ่น (Custom Reminders):** ตั้งเตือนล่วงหน้าได้หลายช่วงเวลาพร้อมกัน เช่น 1 สัปดาห์, 1 วัน, 1 ชั่วโมง หรือกำหนดจำนวนนาทีล่วงหน้าตามต้องการ
* **ระบบป้องกันการปั๊มคะแนน (Anti-farming/Abuse Protection):** หากทำภารกิจเสร็จภายในเวลาต่ำกว่า 5 นาทีหลังจากสร้าง จะไม่ได้รับคะแนน XP เพื่อป้องกันสแปม
* **ระบบสถิติ Streak:** นับจำนวนวันที่ทำภารกิจสำเร็จติดต่อกัน เพื่อสนับสนุนการรักษาวินัยอย่างสม่ำเสมอ

### 2. ระบบโครงการกลุ่มและการทำงานร่วมกัน (Collaborative Projects & Group Tasks)
* **การจัดการโครงการย่อย (Group Tasks):** สามารถรวบรวมภารกิจย่อย (Subtasks) มารวมไว้ภายใต้หัวข้อโครงการเดียวกัน (Project)
* **การกระจายหน้าที่รายบุคคล:** สามารถกำหนดสมาชิกผู้รับผิดชอบ ผู้ช่วย (Co-assignees) ระดับความยากของงาน (Difficulty), ปริมาณงาน (Workload), และความเสี่ยง (Risk) แยกรายคน
* **ระบบส่งตรวจและรีวิวงาน (Leader Review Sheet):** สมาชิกจะต้องแนบลิงก์ส่งงาน จากนั้นหัวหน้าโครงการ (Leader) จะเป็นผู้ตรวจสอบเพื่อกดอนุมัติ (Approve) หรือส่งกลับแก้ไข (Reject) เมื่ออนุมัติแล้วสมาชิกจึงจะได้รับคะแนน XP
* **ระบบสนทนาท้ายภารกิจ (Task Comments):** พูดคุยสอบถามและปรึกษาความคืบหน้าของงานแต่ละชิ้นได้เรียลไทม์ภายในแอป

### 3. ระบบแนวคิดเกม (Gamification System)
* **เลเวลและการสะสมค่าประสบการณ์ (XP & Leveling System):**
  * เลเวลอัปทุกๆ 500 XP
  * เลเวลสูงสุดที่รองรับในระบบคือเลเวล 25
  * รับรางวัลโบนัส XP พิเศษทุกครั้งเมื่อเลเวลเพิ่มขึ้น
* **ของรางวัลระดับขั้น (Milestone Rewards):** ปลดล็อกกรอบรูปโปรไฟล์หรูหราตามเลเวลเป้าหมาย:
  * 🥉 เลเวล 5: กรอบทองแดง (Bronze Frame)
  * 🥈 เลเวล 10: กรอบมาสเตอร์ (Master Frame)
  * 👑 เลเวล 15: มงกุฎแห่งความสำเร็จ (Ultimate Crown)
  * 💎 เลเวล 20: กรอบเพชร (Diamond Frame)
  * 🌌 เลเวล 25: กรอบระดับตำนาน (Mythic Frame)
* **ระบบความสำเร็จและตราเกียรติยศ (Achievements):** ปลดล็อกเพื่อรับคะแนน XP ก้อนใหญ่ เช่น:
  * **นักบุกเบิก (Pathfinder):** ทำภารกิจส่วนตัวสำเร็จ 10 งาน
  * **เจ้าแห่งภารกิจ (Task Master):** ทำภารกิจส่วนตัวสำเร็จ 50 งาน
  * **นักทำภารกิจระดับตำนาน (Legendary Worker):** ทำภารกิจส่วนตัวสำเร็จ 100 งาน
  * **ประกายไฟแรก (Spark):** รักษา Streak ต่อเนื่อง 3 วัน
  * **ไฟลุกไม่หยุด (On Fire):** รักษา Streak ต่อเนื่อง 7 วัน
  * **ไม่มีใครหยุดได้ (Unstoppable):** รักษา Streak ต่อเนื่อง 30 วัน
  * **เพื่อนร่วมทีม (Team Player):** ทำงานกลุ่มในฐานะสมาชิกสำเร็จ 5 งาน
  * **หัวหน้าทีม (Squad Captain):** ทำงานกลุ่มในฐานะหัวหน้าสำเร็จ 20 งาน

### 4. ระบบโซเชียลและการจัดอันดับ (Social Features)
* **ระบบเพื่อน (Friend System):** ส่งคำขอเป็นเพื่อน (Friend Requests), ตรวจสอบรายการที่ได้รับ (Received Requests), และกดยอมรับเพื่อน
* **การดูข้อมูลส่วนตัวเพื่อน (Friend Profile Detail):** เข้าไปตรวจดูเลเวล, ตราความสำเร็จที่ปลดล็อกแล้ว, และสถิติการทำภารกิจของเพื่อนได้

### 5. ระบบแจ้งเตือนหลังบ้านอัจฉริยะ (Smart Backend Notifications)
* **การประมวลผลบนคลาวด์:** ใช้ Cloud Functions คอยสแกนตรวจสอบกำหนดส่งทุกๆ 1 นาที
* **การแจ้งเตือนหลายรูปแบบ:**
  * แจ้งเตือนตามสเตจของเวลา เช่น เหลือเวลา 1 สัปดาห์, 1 วัน, 1 ชั่วโมง หรือเวลาเตือนกำหนดเอง
  * แจ้งเตือนเมื่อถึงเดดไลน์พอดี (Exact Deadline)
  * แจ้งเตือนติดตามผล (Follow-up) หากภารกิจเลยเวลามา 30 นาทีแล้วยังไม่ทำเครื่องหมายว่าเสร็จ
  * ส่ง Push Notification เด้งเข้าโทรศัพท์ทันทีผ่าน Firebase Cloud Messaging (FCM) ทั้งตอนเปิดและปิดแอป

## 🛠️ โครงสร้างเทคโนโลยี (Technology Stack)

* **Frontend:**
  * **Flutter (Dart SDK ^3.11.0)** - ใช้สำหรับพัฒนาแอปพลิเคชันที่รองรับการใช้งานแบบข้ามแพลตฟอร์ม
  * **Provider (^6.1.1)** - สถาปัตยกรรมและเครื่องมือในการจัดการสถานะ (State Management)
  * **Table Calendar (^3.1.1)** - แสดงผลตารางนัดหมายและปฏิทินงาน
  * **Flutter Animate & Animated Text Kit** - เพิ่มประสิทธิภาพในการแสดงแอนิเมชันและเอฟเฟกต์พลุเฉลิมฉลอง (Confetti) ให้ UI ดูพรีเมียม
  * **Flutter Local Notifications & Firebase Messaging** - จัดการ Push Notifications ในฝั่งหน้าบ้าน
* **Backend (Serverless on Firebase):**
  * **Firebase Authentication:** จัดการการล็อกอินและการสมัครสมาชิก (รองรับ Google Sign-In)
  * **Cloud Firestore:** ฐานข้อมูล NoSQL แบบเรียลไทม์สำหรับจัดเก็บข้อมูลผู้ใช้ งาน โครงการ และประวัติการแจ้งเตือน
  * **Firebase Storage:** ใช้จัดเก็บไฟล์แนบสำหรับงานกลุ่มและรูปภาพประจำโปรไฟล์ผู้ใช้
  * **Cloud Functions (Node.js/JavaScript):** ระบบประมวลผลหลังบ้านแบบ Serverless คอยเช็กกำหนดเวลาส่งอัตโนมัติ

## 📂 โครงสร้างโฟลเดอร์ของโค้ด (Directory Structure)

โค้ดในโปรเจกต์นี้ได้รับการจัดระเบียบอย่างเป็นสัดส่วนตามหลักสถาปัตยกรรมของ Flutter:

```
todoapp/
├── android/                   # โฟลเดอร์การตั้งค่าฝั่ง Android OS
├── ios/                       # โฟลเดอร์การตั้งค่าฝั่ง iOS OS
├── assets/                    # ที่เก็บไฟล์ภาพตราสัญลักษณ์, เสียงเอฟเฟกต์ และทรัพยากรที่ใช้ในแอป
├── functions/                 # โค้ดระบบหลังบ้าน (Firebase Cloud Functions)
│   ├── index.js               # สคริปต์หลักในการประมวลผลเดดไลน์และสั่งส่งข้อความแจ้งเตือนผ่าน FCM
│   └── package.json           # รายชื่อ Library หลังบ้าน
└── lib/                       # โฟลเดอร์หลักสำหรับพัฒนาโค้ด (Frontend)
    ├── main.dart              # จุดเริ่มต้นการทำงานของแอป (App Entry Point)
    ├── firebase_options.dart  # ไฟล์เชื่อมต่อข้อมูล Firebase
    ├── config/                # เก็บการตั้งค่าสี ฟอนต์ และการตกแต่ง UI ของแอป
    ├── models/                # แบบแปลนโครงสร้างข้อมูล (Data Models) เช่น Task, User, Project, XP
    ├── providers/             # คลาสสำหรับควบคุม Logic และจัดการข้อมูลในหน้าจอแบบเรียลไทม์ (State Provider)
    ├── screens/               # หน้าจอการใช้งานแต่ละหน้า (UI Screens)
    ├── services/              # คลาสเชื่อมต่อไปยังเซิร์ฟเวอร์ภายนอก (Firestore Service, Sound Service)
    ├── utils/                 # เครื่องมืออเนกประสงค์ (เครื่องมือแปลภาษาไทย, สุ่มข้อมูลเทส, ตัวช่วยย่อเวลา)
    └── widgets/               # ชิ้นส่วนย่อยของหน้าจอที่สามารถนำกลับมาใช้ใหม่ได้ (Reusable Components)
```

## ⚙️ วิธีการติดตั้งและเริ่มต้นใช้งาน (Installation)

### 1. ความต้องการของระบบ (Prerequisites)
* ติดตั้ง **Flutter SDK** (เวอร์ชันล่าสุด หรือ ^3.11.0 ขึ้นไป)
* บัญชี **Firebase Console** ที่เปิดใช้งาน Authentication, Firestore Database, Storage และ Cloud Functions แล้ว

### 2. การตั้งค่าโครงการ
1. โคลนและเปิดโฟลเดอร์โครงการด้วย IDE ของคุณ (เช่น VS Code หรือ Android Studio)
2. ติดตั้ง Dependencies ฝั่งหน้าบ้าน:
   ```bash
   flutter pub get
   ```
3. ดาวน์โหลดไฟล์คอนฟิกจาก Firebase Console และวางไว้ในโครงการตามแพลตฟอร์ม:
   * **Android:** วางไฟล์ `google-services.json` ไว้ใน `android/app/`
   * **iOS:** วางไฟล์ `GoogleService-Info.plist` ไว้ใน `ios/Runner/`

### 3. การรันแอปพลิเคชัน
* **สำหรับฝั่ง Frontend:**
  เชื่อมต่ออุปกรณ์จำลอง (Emulator) หรือเครื่องจริง จากนั้นรันคำสั่ง:
  ```bash
  flutter run
  ```
* **สำหรับฝั่ง Backend (Cloud Functions):**
  1. เข้าสู่โฟลเดอร์หลังบ้าน:
     ```bash
     cd functions
     ```
  2. ติดตั้งแพ็กเกจ Node.js:
     ```bash
     npm install
     ```
  3. Deploy ฟังก์ชันไปยัง Firebase:
     ```bash
     firebase deploy --only functions
     ```
